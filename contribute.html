Contribute

The ACC is a community resource. We rely on you to improve the quality and number of counts.

You can send us:

  1. New counts for species already in the table.
  2. Counts for species that are not in the table.
  3. New references for existing counts.

Please include the scientific name, the 2N or N count (or counts), the reference, and your full name and email. We credit contributors in each release.

The submission form is not ready yet. Email cromanpa@arizona.edu or open a GitHub issue.

Found a mistake in a record? Each species page has a Report a problem section that starts an email to me with the species already filled in.
